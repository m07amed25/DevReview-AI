# Product

## Register

product

## Users

Developers and engineering teams working inside their GitHub pull-request
workflow. They arrive mid-task, reviewing a PR, and need a verdict they can
trust without leaving the review loop. Context spans solo developers, small
teams standardizing a review bar, and orgs running reviews at scale.

## Product Purpose

Code Catch is an AI code reviewer that catches bugs, security issues, and
maintainability problems on every PR before they reach production. It exists
because code review is the highest-leverage moment in software development and
is still slow, manual, and inconsistent. Success is two things: a developer
trusts the AI's findings enough to act on them, and a new user reaches their
first reviewed PR in under a minute.

## Brand Personality

Engineered, confident, luxury. The voice is that of a senior reviewer who is
precise and never hedges: plain domain language, suggestions with context, not
complaints. "Built by developers, for developers." Premium is expressed through
restraint and craft, the feel of a precision instrument, never ornament.

## Anti-references

- **Vercel** monochrome-glow marketing minimalism: the gradient-lit black-and-
  white look every dev tool now copies. Code Catch is cold engineered navy, not
  that template.
- **Twitter / X**: engagement-driven, noisy feeds and dopamine loops. Code
  Catch is a focused instrument, not a social surface.
- **Facebook**: cluttered consumer-social chrome and ad-driven density. Density
  here stays aligned and purposeful.
- Behaviorally, not CodeRabbit / Sourcery's failure modes: bots that comment on
  every line, vague "consider refactoring" notes, or black-box scores with no
  reasoning.

## Design Principles

- **Earn the act.** Every finding shows its reasoning. Trust is the product; no
  black-box scores.
- **First PR in sixty seconds.** Zero-config path to value. Nothing stands
  between connecting a repo and the first review.
- **Instrument, not feed.** Dense and aligned like a control room, never a
  noisy, attention-seeking social surface.
- **Engineered luxury.** Precision and restraint read as premium. One signal,
  one family, no decoration.
- **Suggestions with context.** Speak the codebase's language plainly; explain,
  don't just flag.

## Accessibility & Inclusion

WCAG 2.1 AA across the product. Body and secondary text clear 4.5:1 on every
navy surface; status is always paired with text or an icon, never color alone.
Honor prefers-reduced-motion and maintain visible keyboard focus throughout.
